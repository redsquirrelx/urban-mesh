# AC-111 — Motivos de cambio independientes

| Políticas | Autoridad que provoca cambio | Área que debe mantenerse estable |
|---|---|---|
| Caminos y duración | Planificador de transporte | Promociones y campañas |
| Ofertas y elegibilidad | Equipo de relación con pasajeros | Planificador de rutas |
| Tarifas y descuentos | Política tarifaria | Cumplimiento regulatorio |
| Registro de auditorías | Oficina regulatoria | Motor de precios |
| Boletos emitidos | Sistemas de recaudo | Programador de marketing |
| Avisos a pasajeros | Centro de comunicaciones | Evaluación de mantenimiento |
| Reparaciones | Taller de flota | Distribución de avisos |
| Turnos | Legislación laboral | Cálculo de horarios |
| Reportes | Analítica operacional | Retención y purgas |
| Calidad ambiental | Equipo de sensores | Notificación y transporte |
| Calibración | Metrología | Driver del dispositivo |
| Cadena de custodia | Unidad de auditoría | Diseño de almacenamiento |
| Stock y reservas | Logística | Cobro y comunicación |
| Cobros | Proveedores financieros | Lógica de negocio |
| Formatos HTTP y correo | Canales digitales | Dominio y casos de uso |
| Autorización de excepciones de calidad | Equipo de control de flota | Clasificación y almacenamiento |
| Presupuestos de suministros | Logística de depósitos | Procesamiento de pagos |

Una secuencia coordinada de casos de uso es una responsabilidad válida de orquestación. La señal de separación no es la cantidad de operaciones llamadas, sino la presencia de decisiones autónomas o efectos que deberían quedar bajo otra política y autoridad de cambio.
