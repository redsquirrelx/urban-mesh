# Glosario

- **Ruta:** secuencia ordenada de paradas y tiempos entre tramos.
- **Viaje:** opción de desplazamiento en transporte público, previa al billete.
- **Billete:** derecho de acceso emitido a una ruta con precio registrado.
- **Alquiler:** uso temporal de una bicicleta entre apertura y cierre.
- **Política tarifaria:** objeto que produce el total final de una cotización.
- **Gateway:** puerto para proveedor de transporte, dispositivo o comunicación.
- **Recibo normalizado:** entidad `PaymentReceipt` sin vocabulario de proveedor.
- **Lectura de sensor:** medición con unidad, marca temporal y dispositivo.
- **Calibración:** transformación metrológica independiente del lector.
- **Calidad:** clase `accepted`, `hold` o `rejected` de una lectura.
- **Cadena de custodia:** registro temporal de acciones sobre sensores y mediciones.
- **Retención:** eliminación explícita de datos según política temporal.
- **Stock:** cantidad disponible de una pieza en depósito.
- **Puerto:** contrato declarado por la aplicación para una dependencia externa.
- **Raíz de composición:** módulo que construye y enlaza colaboradores concretos.
